

phase-1: setup postgresql database
------------------------------------------
step-1: create postgresql database container
step-2: connect using psql client ( cli )
step-3: create table(s)

phase-2: setup spring boot application
------------------------------------------
step-1: create spring boot application using spring initializer or VS code extension
step-2: add dependencies for spring data jpa ,postgresql driver, spring web
step-3: configure application.properties for database connection
step-4: create entity class for the table created in phase-1
step-5: create repository interface for the entity class
step-6: create service class to handle business logic
step-7: create controller class to handle HTTP requests
step-8: test the application using postman or curl
