

phase-1: setup postgresql database
------------------------------------------
step-1: create postgresql database container
step-2: connect using psql client ( cli )
step-3: create table(s)

phase-2: setup spring boot application
------------------------------------------
step-1: create spring boot application using spring initializer or VS code extension
step-2: add dependencies for spring data jpa ,postgresql driver, spring web
step-3: configure application.properties for database connection
step-4: create entity class for the table created in phase-1
step-5: create repository interface for the entity class
step-6: create service class to handle business logic
step-7: create controller class to handle HTTP requests
step-8: test the application using postman or curl


phase-3: Spring AI integration
------------------------------------------

- step-1: add dependencies for spring ai ( spring boot starter ai )
- step-2: create a service class to handle AI related logic
   Req-1- from todo title & description, need to identify the category of the todo ( work, personal, shopping, etc ) using spring ai


phase-4: OpenAPI / Swagger UI integration 
------------------------------------------
- step-1: add dependencies for springdoc-openapi-ui
- step-2: configure application.properties to set the path for swagger ui
- step-3: test the swagger ui by accessing the configured path in the browser ( e.g. http://localhost:8080/swagger-ui.html )


phase-5: Security ( Authentication & Authorization )
------------------------------------------
- step-1: add dependencies for spring security
- step-2: configure security settings 
- step-3: implement register and login functionality to generate JWT tokens
- step-4: secure the API endpoints using JWT tokens
