## 5. 🧠 Spring Core Concepts

### Bean

* Object managed by Spring container
* Created via:

  * `@Component`, `@Service`, `@Repository`
  * `@ComponentScan`

### Bean Lifecycle

**High-level flow:**

1. Create ApplicationContext
2. Scan classes
3. Create BeanDefinitions
4. BeanFactoryPostProcessor 🔥
5. Instantiate beans
6. Dependency injection
7. BeanPostProcessor 🔥
8. Initialization
9. App ready

**Detailed lifecycle:**

1. Load Bean Definitions
2. BeanFactoryPostProcessor
3. Instantiate Bean
4. Inject Dependencies
5. Aware Interfaces
6. BeanPostProcessor (before)
7. `@PostConstruct`
8. BeanPostProcessor (after)
9. Bean Ready
10. `@PreDestroy`

---

## 6. 🔥 Configuration Priority (Spring Boot)

**VERY IMPORTANT ORDER:**

```
1. Command line arguments
2. Environment variables
3. External config (outside JAR)
4. application.properties (inside)
5. @Value default
```

👉 CLI > ENV > External > Properties > Default

## 11. 📊 CAP Theorem

* You can only choose 2:

  * Consistency (C)
  * Availability (A)
  * Partition Tolerance (P)

### Example

* AP system → Cassandra

  * High availability
  * Eventual consistency

### Formula Insight

```
CLread + CLwrite > RF
```

* Ensures strong consistency in distributed DB

## 12. 🐳 Containers & Deployment

### Container Flow

```
Dockerfile
   ↓
docker build
   ↓
Image (OCI standard)
   ↓
Push → Registry
   ↓
docker pull
   ↓
docker run
   ↓
Container
```

### Standards

* Open Container Initiative

### Docker Example (PostgreSQL)

```bash
docker run --name todo-postgres \
  -e POSTGRES_USER=todo_user \
  -e POSTGRES_PASSWORD=todo_pass \
  -e POSTGRES_DB=todo_db \
  -p 5432:5432 \
  -d postgres:16
```
